구현 기능 목록

1. 입력 처리 기능
방문 날짜 입력

1 이상 31 이하의 숫자로만 입력받기
유효하지 않은 입력 처리 ([ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요.)
주문 입력

올바른 형식(e.g. 해산물파스타-2,레드와인-1,초코케이크-1)으로 입력받기
메뉴판에 없는 메뉴 입력 시 오류 처리 ([ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.)
개수가 1 이상이 아닐 경우 오류 처리 ([ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.)
중복 메뉴 입력 시 오류 처리 ([ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.)

2. 주문 검증 및 예외 처리
총 주문 개수 제한

주문한 메뉴 개수 총합이 20개를 초과하면 오류 처리
총 주문 금액 제한

총주문 금액이 10,000원 미만일 경우 이벤트 적용 불가
음료만 주문 제한

음료만 주문할 경우 오류 처리

3. 주문 금액 계산 기능
할인 전 총 주문 금액 계산

주문한 각 메뉴의 가격을 계산하여 총 주문 금액 출력
할인 내역 적용

크리스마스 디데이 할인 (12월 1일~25일, 날짜에 따라 할인 금액 증가)
평일 할인 (일~목요일: 디저트 메뉴 1개당 2,023원 할인)
주말 할인 (금·토요일: 메인 메뉴 1개당 2,023원 할인)
특별 할인 (이벤트 달력에 별이 있는 날: 1,000원 할인)
증정 메뉴 계산

할인 전 총주문 금액이 120,000원 이상일 경우 샴페인(25,000원) 증정
총혜택 금액 계산

총혜택 금액 = 할인 금액 합계 + 증정 메뉴의 가격
할인 후 예상 결제 금액 계산

할인 후 예상 결제 금액 = 할인 전 총주문 금액 - 할인 금액

4. 출력 기능
주문 정보 출력

고객이 주문한 메뉴와 개수 출력
할인 전 총 주문 금액 출력

주문 메뉴 총합 출력
증정 메뉴 출력

샴페인 증정 여부 결정 및 출력 (없음 또는 샴페인 1개)
혜택 내역 출력

적용된 이벤트 내역 출력 (혜택이 없으면 없음)
총혜택 금액 출력

할인 및 증정 금액 포함하여 출력
할인 후 예상 결제 금액 출력

최종 결제 금액 출력
이벤트 배지 부여 및 출력

5,000원 이상: 별 ⭐
10,000원 이상: 트리 🎄
20,000원 이상: 산타 🎅
혜택이 없으면 없음 출력
